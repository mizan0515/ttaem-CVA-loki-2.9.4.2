# 기능과 공개 범위

이 저장소는 **Loki 2.9.4.2의 단일 VOD 흐름을 제공한다.** 3.0.1에서는 자막·타이밍 전처리 개선만 유지하며 의미 분석 엔진은 2.9.4.2를 사용한다. 관리자 화면은 리포트 목록, 작업공간, 게시 준비에 필요한 최신 화면만 포함한다.

기능 누락과 의도적으로 제외한 범위를 구분한다. Codex가 작성하는 문구는 실행 시점과 입력에 따라 달라질 수 있지만, 결과 구조와 검증 계약은 이 문서의 범위를 따른다.

## 기준

- 의미 분석: 채택된 Loki 2.9.4.2의 관찰·D1/D2·Point/Story·Highlight 계약과 프롬프트.
- 결과 화면: 해당 버전의 기존 report.html/viewer.css/viewer.js/Highlight 카드. 공개 데이터 경계를 적용하되 디자인을 새로 만들지 않는다.
- 관리자 화면: 최신 홈·리포트 목록·report-workspace의 필요한 화면과 동작만 사용.
- 3.0.1: 단어 시각 기반 타이밍 보정, 짧은 발화 표시 모듈, 선택 목소리 참조 등록/인코더만 선별. 후속 의미 분석 엔진 전체는 포함하지 않는다.
- LLM: 이 폴더를 연 Codex 세션만 사용. 별도 API 키·Free API·Claude 모델 호출·자동 대체 경로 없음.

## 기능 상태

| 기능 | 공개판 상태 |
|---|---|
| 단일 공개 CHZZK VOD 링크, 메타데이터, 음성 취득 | 구현·실제 VOD 확인. 로그인이나 제한 우회 없음 |
| 로컬 Whisper 전사, 단어 시각, VAD | 새 모델 다운로드 후 CUDA·CPU 각각 전체 VOD 확인. 속도/자원은 기기에 따라 다름 |
| 재생 채팅 수집·정렬·부분 수집 상태 | 구현. 식별자 제외, 원문은 로컬 |
| 청크 관찰·방송 구조 D1/D2 | 채택 코어와 프롬프트 연결·실제 생성 |
| Point와 연결된 Story | 코어 연결·실제 생성·편집 |
| Highlight 발견·선택·구간 작성 | 코어 연결. 0..N, 단일 VOD 안의 여러 source span 표현 가능 |
| 기존 결과 템플릿·목차 이동·Story 펼침·카드·장면 도구 | 원본 템플릿 재사용, 공개 DTO만 입력 |
| 채팅 그래프 | 시간 구간별 개수만 공개. 메시지와 시청자 식별자는 제외 |
| 관리자 홈·목록·검색·작업공간 | 최신 레이아웃 선별. 다른 제품/관제 메뉴 제외 |
| 영상 확인·시간 조정·수정·저장·재열기·복원 | 구현, 실제 브라우저 확인. 원래 생성 결과와 저장 이력 보존 |
| 저장본 미리보기·게시 준비 | 구현. 자기 사이트용 정적 파일 또는 ttaem.com 요청용 JSON 선택 |
| 결과물 요약 방식·영상 연결 | 상단에 `요약 방식: Loki 2.9.4` 표시. 검증된 CHZZK VOD 창을 연결해 장면·시간 클릭으로 같은 영상의 해당 시점 이동 |
| Codex 요청 파일과 응답 캐시 | 구현. 요청 내용 해시가 일치하는 응답으로만 재개 |
| 3.0.1 타이밍·짧은 발화 표시 | 연결. 화자 이벤트 입력이 없는 경우 신원/끼어들기를 지어내지 않음 |
| 선택 목소리 참조 | 사용자 녹음·명시적 채널 활성화·조건 확인 모델 필요. 실제 정확도 미검증 |
| 공개 댓글 시간표 | 실제 API 수집 → 원본 선별/앵커 → 요약 입력. 수집 실패와 선별 0개 구분 |
| 채팅 반응·오디오 피크·원본 청크 분할 | 원본 알고리즘 복원. 같은 실제 입력으로 기준 revision 실행 결과와 일치 확인 |
| 시청자 클립 | 방송 시각 범위 수집, 같은 VOD/시점 확인, 반응 순위, 요약 입력과 기존 카드 연결. 동영상 파일 다운로드·편집은 아님 |
| 비공개 분석 근거 | 원본 5개 신호 종류와 댓글·클립을 분석 근거 보기에서 확인. 공개 JSON/정적 파일에는 원문 제외 |
| 채널별 어휘·자막 표기 보정 | 이용자가 만든 정확한 채널의 승인 사전, 현재 자료 어휘, Whisper 힌트·승인 별칭 보정. 운영자 사전 미포함 |
| 공개 커뮤니티 맥락 | 원본 파싱·순위·방송 시간 필터. 익명 HTTP, 오래된 VOD 생략, 차단/실패 구분. 차단 우회 없음 |
| 승인 콘텐츠 이름 카드 | 이용자의 로컬 승인 카드만 원문 정확 일치 조건으로 최대 6개 목차 입력. 운영자 카드 미포함 |
| 선택 시각 자료 | 원본 정규화와 목차 보조 소비 경로 복원. 해당 VOD의 로컬 sidecar만 읽으며 OCR 원문·프레임은 제외. 자동 화면 분석을 수행했다고 표시하지 않음 |
| ttaem.com 제출 접수·심사·외부 게시 | 로컬 관리자에서 검토용 JSON 준비와 운영 중인 공식 접수 페이지 연결. 접수·심사·호스팅은 별도 운영 서비스 |

## 포함하지 않는 것

VOD 합치기, 여러 시점 정렬, 컷/MP4/쇼츠 제작, 작품 이야기 제품, 범용 웹 조사, 카페/SNS 자동 게시, 계정·브라우저 자동화, 방송 감시·대량 큐·서버 관제, 여러 PC 동기화, 내부 에이전트 관제·개발 기록은 포함하지 않는다.

실제 운영 설정·인증정보·개인 사전·수정/학습 이력·원본 미디어·전체 자막·채팅·개인 목소리 녹음·프로필·벡터·모델 가중치·기존 Git 이력·BAT/CMD 파일을 배포하지 않는다. 파일이 Git에서 무시된다고 작업 폴더 전체를 압축해도 된다는 뜻은 아니다.

## 공개 경계

1. 소스 배포: 파일별로 검토한 코드·프롬프트·템플릿·합성 테스트·설치 안내·정책·로고·제3자 고지만 포함한다.
2. 독자용 페이지: 허용된 요약 필드와 집계, 검증된 원본 시각 링크만 렌더링한다. 내부 결과 JSON을 그대로 내보내지 않는다.
3. 로컬 관리자: 원자료·현재 수정본·이력은 로컬에 보관한다. 관리자 서버는 루프백 전용이며 정적 페이지와 함께 인터넷에 노출하지 않는다.

필수 로고와 ttaem.com 표시는 모든 생성 페이지 하단에 유지한다. 실제 VOD 생성 결과를 공개 데모에 포함하려면 그 결과 자체를 별도 검토한다.
