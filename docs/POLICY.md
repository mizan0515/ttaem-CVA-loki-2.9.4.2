# TTaem CVA 공개판 정책 v1.0

이 문서는 공개 프로젝트의 이용 정책을 설명한다. 구체적인 이용허락 문구는 [LICENSE](../LICENSE)를 따르며, 외부 코드·모델과 기존에 적법하게 부여된 권리는 별도로 유지한다.

## 확정한 기본 권한

| ID | 행위 | 정책 |
|---|---|---|
| P01 | 비상업적 개인 사용 | 허용 |
| P02 | 개인적인 코드 수정 | 허용. 그 자체로 상업 이용·독립 배포 권한을 부여하지 않음 |
| P03 | 공식 저장소에 기여하기 위한 포크·수정·PR 제출 | 허용 |
| P04 | 상업적 이용 | 권리자의 사전 명시적 서면 허가 필수 |
| P05 | 수익화된 스트리머·유튜버의 자기 방송 요약 | 상업적 이용에 포함. 사전 허가 필수 |
| P06 | 변형판을 별도 제품·배포판·패키지로 배포 | 기본 금지. 허가받은 사람·단체만 허가 범위에서 가능 |
| P07 | 생성 페이지의 표시 | 모든 생성 요약 페이지 하단에 TTaem CVA 로고와 `ttaem.com`을 표시·유지 |

무료 배포라는 이유로 P06의 예외가 되지 않는다. 기여용 포크를 독립 서비스·제품 배포용으로 전환하면 해당 허가가 필요하다. GitHub 서비스 자체가 허용하는 열람·포크 권리는 존중하며, 정책에서 포크 자체를 전면 금지한다고 표현하지 않는다.

## 상업적 이용과 배포의 해석

상업적 이용에는 유료 서비스·제작 대행·기업 업무·수익화 채널의 콘텐츠 제작 및 운영, 광고·후원·유료회원 수익 활동에 연결된 이용을 포함한다. 개인이 수정한 버전을 상업 목적으로 사용하는 경우도 사전 허가 대상이다.

프로그램을 타인에게 서비스로 제공하는 경우를 단순 개인 사용으로 취급하지 않는다. 코드를 전달하지 않는 서비스 제공도 허가 범위를 확인해야 한다. 기능을 우회 포장한 플러그인·컨테이너·설치 프로그램·호스팅 서비스도 실제 행위를 기준으로 판단한다.

원본 프로그램의 별도 미러·패키지 재배포도 기여용 포크와 별도 서면 허가 외에는 허용하지 않는다. 공식 저장소·공식 배포 링크 공유는 가능하다. 제3자 구성요소가 자체 라이선스로 부여하는 권리는 제한하지 않는다.

## 결과물과 브랜드

- 허용된 비상업적 이용으로 만든 요약 페이지는 원본 콘텐츠에 필요한 권리를 갖춘 범위에서 공유할 수 있게 한다. 상업적 결과물 사용은 별도 허가 범위를 따른다.
- 페이지 하단에는 제공한 로고와 읽을 수 있는 `ttaem.com` 텍스트 링크를 함께 둔다. 기본 문구는 `Powered by TTaem CVA · ttaem.com`이다.
- 로컬 미리보기·내보낸 HTML·게시본에서 표시를 유지한다. 로고 로딩 실패 시에도 사이트명 텍스트가 남도록 한다.
- 로고를 숨김·잘림·투명화하거나 다른 브랜드로 교체하지 못하도록 프로그램·템플릿 이용 조건에 명시한다.
- 필수 출처 표시를 위한 로고 사용은 허용한다. 별도 서비스의 대표 로고로 사용하거나 공식 제휴·보증으로 오인시키는 사용은 별도 허가 대상이다.
- 코드·템플릿·로고·AI 생성 내용·VOD·음성·이미지·채팅의 권리를 구분한다. 생성 내용 전체나 원본 방송의 권리를 프로젝트가 소유한다고 일괄 선언하지 않는다.

## 기여와 허가 운영

- 기여자는 제출 권한을 갖춘 코드만 제공한다. 비밀값·개인 데이터·무단 복제 코드는 받지 않는다.
- 병합 전에 [기여 동의 문안](../CONTRIBUTING.md)에 명시적으로 동의해야 한다. 기여자 저작권을 유지하면서 프로젝트 수정·배포·별도 상업 라이선스 제공 권한을 확보한다. PR 제출만으로 저작권이 자동 이전된다고 주장하지 않는다.
- 상업 이용 허가와 변형판 배포 허가는 구분한다. 허가서에는 주체, 대상 채널·제품·서비스, 목적, 기간, 재배포 범위, 브랜드 조건을 기록한다.
- 재허가·양도는 별도로 허용한 경우에만 가능하다. 상업 이용·변형판 배포와 정책의 공식 문의 경로는 `ttaem00@naver.com`이며, 개별 허가서에는 권리자·이용자 식별과 허가 범위를 구체적으로 적는다. 위반 시 이용허락 종료와 서면 시정·복구 조건은 LICENSE 및 개별 허가서를 따른다.
- 이용자의 모델·전사·호스팅 계정과 비용은 별도다. 프로젝트 허가가 외부 서비스나 모델의 이용 허가를 대신하지 않는다.

1. 프로젝트가 권리를 가진 코드·프롬프트·로고에만 이 정책을 적용한다. 원본 파일·기존 수령인의 조건을 소급 변경하지 않는다.

3. 기존에 적법하게 부여된 권리를 소급 회수한다는 표현을 사용하지 않는다.
4. LICENSE·기여 동의·브랜드 규정을 일치시킨다. 이 사용자 지정 문안의 법적 집행력을 보증하지 않으며, 개별 상업 계약과 관할 법률 쟁점은 필요시 전문 검토한다.
