# 선택형 자막·목소리 참조 기능

상태: 선택형 준비·활성화·관찰 어댑터 구현. 실제 ERes2NetV2 가중치의 권리·정확도 검증은 미완료이며 기본 비활성.

정책: 개인별 녹음·프로필과 외부 모델 조건을 명시하고 **목소리 참조를 사용할 수 있는 선택 기능으로 열어 둔다.** 개인 자료나 가중치를 제품과 함께 배포하는 허가는 아니다.

## 현재 기능의 의미

현재 확인한 목소리 참조 구현은 사용자가 지정한 정확한 채널의 참조 음성과 비교한 점수를 관찰한다. 그 점수는 확률이나 화자 신원 증명이 아니다. 화자를 확정하거나 다른 사람의 대사를 지우거나 이 점수로 SRT를 자동 수정하지 않는다. TTS·목소리 복제·일반적인 신원 식별·전체 방송의 완성된 화자 분리 기능으로 소개하지 않는다.

자막 타이밍·짧은 발화 분리·음악 표시는 목소리 참조와 독립적이다. 참조가 꺼져 있거나 준비되지 않아도 기본 요약과 독립 자막 기능은 사용할 수 있어야 한다.

## 공개판 활성화 흐름

1. 기능 안내에서 용도·한계·로컬 저장 대상·모델 조건을 읽는다. 기본은 미활성 상태로 배포한다.
2. 이용자가 사용 권한을 가진 실제 해당 화자의 녹음을 직접 준비한다. 타인의 녹음을 자동 수집·등록하지 않는다.
3. 정확한 채널을 지정하고 녹음 형식·출처·파일 무결성을 확인한다.
4. 이용자가 별도로 확보한 호환 인코더의 출처·revision·라이선스·체크섬을 확인한다.
5. 새 프로필 revision을 만들고 미리보기 후 명시적으로 활성화한다. 생성만 했다고 자동 활성화하지 않는다.
6. 해당 채널 VOD에서 관찰 결과를 로컬 검토한다. 다른 채널·프로필 없음·손상·모델 부재는 이유를 알리고 참조만 비활성화한다.
7. 끄기·이전 revision 선택·사용자 지정 자료 삭제 절차를 제공한다. 자동 정리로 원음·프로필을 삭제하지 않는다.

Codex가 준비·등록 절차를 도울 수 있지만 사용 권한·대상 채널·활성화 선택은 이용자의 명시 입력에 따른다. 기존 세 관리자 화면에 상세 프로필 관리 제품을 추가하지 않고, 초기에는 별도 준비 명령으로 사용하며 결과는 로컬 JSON에만 저장한다.

## 입력·저장 조건

검토한 원본 계약은 16 kHz 모노 PCM16 WAV, 조각당 1~30초, revision당 1~64개를 허용한다. 수량은 품질 보증이 아니다. 다른 날짜·상황의 음성으로 실제 효과를 확인해야 한다.

원음, 채널별 manifest, 참조 임베딩, 활성화 포인터, 관찰 점수는 사용자 로컬 런타임에 저장한다. 이 자료를 Git·공개 패키지·생성 페이지·진단 업로드에 넣지 않는다. 모델 추론과 등록은 정상 요약 중에 자동 다운로드·설치·학습을 시작하지 않는다.

2026-09-18 확인: [3D-Speaker LICENSE](https://github.com/modelscope/3D-Speaker/blob/main/LICENSE), [AST 모델 카드](https://huggingface.co/MIT/ast-finetuned-audioset-10-10-0.4593).

정확한 [ERes2NetV2 모델 페이지](https://modelscope.cn/models/iic/speech_eres2netv2w24s4ep4_sv_zh-cn_16k-common/summary)는 이번 조회 도구에서 접근되지 않았다. 따라서 해당 가중치의 배포·상업 이용 가능 여부를 확정하지 않는다. 공식 배포 설치 경로를 제공하기 전에 정확한 모델 조건과 재현 가능한 출처를 확보한다. 이는 선택 기능의 준비 과제이며 기본 요약 엔진 전체를 무조건 막는 이유로 확대하지 않는다.

TTaem CVA의 상업 이용 허가와 외부 모델의 허가는 별개다. 프로젝트의 제한 정책을 독립적인 제3자 구성요소의 원 라이선스를 대체하는 것으로 표시하지 않는다.

## 검증 기준

- 모델·프로필 없는 새 환경에서도 기본 파이프라인이 실행되고 준비되지 않은 이유가 표시됨.
- 정확한 채널에서만 유효한 프로필이 동작하며 다른 채널의 프로필을 대체 사용하지 않음.
- 입력 파일·revision·체크섬 변조와 경로 이탈을 거부함.
- 등록·활성화·참조 끄기·이전 revision 복귀가 분리되고 기존 자료를 덮어쓰지 않음.
- 실제 로컬 모델로 준비→프로필 생성→한 번의 관찰→비활성화를 확인함. 과거 테스트 기록을 새 공개판의 PASS로 재사용하지 않음.
- 참조 점수가 public HTML·embedded JSON·source map·게시 자산으로 나오지 않음.
- 타이밍/발화 개선 효과와 목소리 참조의 효과를 각각 평가함. 전체 요약 품질 개선은 대표 VOD 비교 전까지 미검증.

## 공개판 명령

가중치를 자동으로 내려받지 않는다. 권한이 확인된 모델과 해당 화자의 녹음은 프로젝트의 비공개 `.voice/`에 이용자가 준비한다. 원본 녹음은 16 kHz 모노 PCM16, 각 1~30초다. 모델 파일은 호환되는 ERes2NetV2 192차원 체크포인트여야 한다. 외부 모델 조건이 확인되지 않았으면 여기서 중단하고 기본 요약을 계속 사용한다.

선택 런타임 설치: `python setup.py --voice` (CPU) 또는 `python setup.py --voice --cuda`. 큰 다운로드가 발생하며 기본 요약에는 필요하지 않다. 준비 JSON에는 다음 키를 명시한다. 경로는 `.voice/` 기준이며 녹음·모델·JSON을 Git에 추가하지 않는다.

```json
{
  "channel_id": "정확한 CHZZK 채널 ID 32자리",
  "revision": "my-profile-v1",
  "recordings": ["input/authorized-recording.wav"],
  "recording_rights_confirmed": true,
  "model_terms_confirmed": true,
  "model_source_url": "https://공식-모델-출처",
  "model_revision": "확인한 정확한 revision",
  "model_license": "확인한 모델 가중치 이용 조건",
  "encoder_path": "input/encoder.bin",
  "encoder_sha256": "확인한 파일의 SHA-256"
}
```

`PYTHON`은 이 프로젝트 `.venv`의 Python이다.

```text
PYTHON -m ttaem_cva.voice prepare .voice/spec.json
PYTHON -m ttaem_cva.voice activate 채널ID my-profile-v1
PYTHON -m ttaem_cva.voice observe https://chzzk.naver.com/video/번호
PYTHON -m ttaem_cva.voice disable 채널ID
```

준비만으로 활성화되지 않는다. 관찰은 VOD를 prepare한 뒤 별도 명령으로 실행하며 기본 요약의 의미·자막·화자 신원을 바꾸지 않는다. 다른 채널·없는 모델·손상된 체크섬은 비활성/실패로 표시한다. 끄기는 원음·벡터를 삭제하지 않으며 이전 revision을 다시 선택할 수 있다. 관찰 결과는 `runs/번호/voice-observation-private.json`에만 기록된다.

합성 인코더로 권리 확인·준비/활성화 분리·정확한 채널·손상 거부를 검증한다. 이것을 실제 음성 인코더 품질 PASS로 해석하지 않는다. 실제 모델/권한 있는 녹음이 준비되면 별도의 실제 관찰 검증이 필요하다.
